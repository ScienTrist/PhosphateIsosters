PHIP — Phosphate Isostere Hit Picker

You'll be shown a reference phosphate-binding site (green ligand) and a candidate "hit" ligand (highlighted) superimposed in the same pocket. Red atoms on the hit are ones our pipeline matched as making the same kind of contact as the reference; purple atoms belong to the same chemical group but weren't matched directly. Rate how convincing the hit is as a phosphate isostere in that pocket, from 1 (not at all) to 5 (excellent mimic). You can rotate, zoom and pan the structure freely with your mouse/trackpad.

Non-carbon atoms (O, N, S, P) always use standard element colors, regardless of side. Metal ions (spheres, green/cyan by side) are labeled the same way as binding residues. Dashed lines (green = reference, cyan = hit) connect each interacting ligand atom to the exact residue atom it interacts with — only interactions the hit actually replicated are shown (same set the score is computed from), not every contact the reference phosphate makes. "All residues within 6Å" shows the full local environment (thin, unlabeled sticks) regardless of whether ProLIF detected a real interaction — off by default since it can get crowded. Explicit hydrogens are loaded but hidden by default for the same reason; turning them on doesn't affect the interaction lines above, which already use hydrogen atoms (e.g. an Arg's HH12) when that's the real interacting atom, whether or not they're shown.
